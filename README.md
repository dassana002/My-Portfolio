# Dassana Thathsara - Portfolio Website

A modern, responsive portfolio website showcasing my work as a Full-Stack Developer.

## Overview

This portfolio website serves as a personal showcase of my skills, experience, and projects. It features a clean, professional design with smooth navigation and responsive layouts.

## Tech Stack

- **HTML5** - Semantic markup structure
- **CSS3** - Custom styling with modern CSS features
- **JavaScript** - Interactive functionality
- **Webpack** - Build tooling and bundling
- **Google Fonts** - Typography (Inter, JetBrains Mono)
- **FontAwesome** - Icon library

## Features

- Responsive design for all screen sizes
- Mobile-friendly navigation with hamburger menu
- Smooth scroll navigation
- Sidebar social links and email contact
- Animated skill progress bars
- Project showcase with technology tags
- Contact section with direct email and WhatsApp links

## Sections

1. **Hero** - Introduction and overview
2. **About** - Skills and professional background
3. **Experience** - Education and work history
4. **Projects** - Featured and other projects
5. **Contact** - Get in touch information

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:

```bash
npm install
```

### Development

Start the development server:

```bash
npm start
```

The site will open at `http://localhost:3000`

### Build

Create a production build:

```bash
npm run build
```
